# LINE lunch decision bot

Build a LINE bot that uses a shared location, budget, and preferences to suggest a small set of open lunch options with map links. Confirm the venue source and opening-hours reliability before design; do not assume a stack or deployment target.

Guard Policy is strict: changed inputs reopen approval, and plan approval, review freeze, state transition, and reviewer scope remain enforced.
