## Test Type Inventory

- 建置、型別、lint、format；沿用 Node 24.18.0 / npm 11.16.0 與既有 node_modules/lockfile。
- 既有 mock-only 單元、MVP 關鍵 integration、synthetic E2E、全部 src 行覆蓋率 ≥80%、offline demo。
- 原效能／資料庫／跨程序與歷史驗證保持延後；本輪不執行，不能算通過。
- 安全邊界測試與金鑰檔忽略檢查；Gitleaks／Semgrep／OSV-Scanner 尚不可用，不以 lint 充當掃描。

## Known Limitations

- 不讀取或複製 `.env`；原檔位置見 `../local-runtime-location.md`。`.env` 與 `.DS_Store` 被 Git 忽略且未追蹤；避免在專案根目錄重建兩者。
- 一次真實 LINE 使用流程已有歷史成功及使用者确认；額度 1/1 已用完，本輪不重啟受控 runner、不新增 Places 呼叫或公開入口。
- 無 hosted CI／必要三類安全掃描結果，不具合併或正式部署 readiness。
- 不新增或刪除任何使用者資料、不改 credentials／webhook／security policy。
