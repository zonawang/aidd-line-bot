原 run `961ab998-0b81-444c-ab33-578c76f008c0` 的 image／PGDATA／evidence 保留。既有 `db/`、`infra/`、`compose.yaml`、infra scripts／tests 不刪除、不改成空測試、不重導到新 backend。未解問題的原失敗紀錄不改寫為成功。
